# SPDB release bundle v1.0.0

Canonical public release artefacts for SPDB v1.0.0.

- `MANIFEST.json` — version, commit (at generation), counts, provenance, file inventory
- `SHA256SUMS` — SHA-256 checksums for inventoried paths
- `samples/` — Wave-1 unit JSONL (+ ParlaMint sample continuity file)

Wave-1 annotations and metrics live under `annotation/pilot_001/` in the repository root.
