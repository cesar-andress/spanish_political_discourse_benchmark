# Datasheet for Datasets — SPDB v1.0.0

## Motivation

SPDB provides reproducible pragmatic-function annotation infrastructure and a
diagnostic two-coder reliability pilot for Spanish parliamentary discourse.

## Composition

- Development pool: ParlaMint-ES-derived units (N = 878 in the project pool used for sampling).
- Wave-1 pilot: N = 100 double-coded units (seed = 42).
- Instruments: codebook-v1.0.0 (Wave-1) and codebook-v1.1.0 (post-pilot revision, not revalidated).

## Collection

Public parliamentary speech via ParlaMint 5.0 (CC BY 4.0). No private messaging
or non-public personal data.

## Annotation

Two independent annotators; pragmatic function only in Wave-1. Observed agreement
0.350; Cohen κ ≈ 0.235; Krippendorff α ≈ 0.223; Fleiss κ ≈ 0.219; 65 disagreements.

## Uses

Research on annotation reliability, guideline revision, and computational
pragmatics. Not intended as adjudicated gold for leaderboard deployment.
