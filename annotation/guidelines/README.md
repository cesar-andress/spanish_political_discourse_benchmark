**Wave-1 note:** Wave-1 annotations remain v1.0-era diagnostic annotations and are not reclassified under v1.1. Do not mix guideline versions in one reliability statistic.

**Prospective material:** blank attestation templates and calibration packages, if present locally, are unused protocol scaffolding for a future wave—not completed evidence in v1.0.0.
